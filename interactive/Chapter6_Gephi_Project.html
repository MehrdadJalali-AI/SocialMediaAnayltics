Section 2

What is Gephi — and how do you install it?

Gephi is a free, open-source desktop tool to explore, analyse and visualise networks. It is used in social network analysis, research and data journalism, fraud and security, marketing, and biology (e.g. the protein networks from Chapter 4).

🖱 Interactive

drag, zoom, select — every change is visible at once

📊 Built-in statistics

degree, PageRank, modularity, paths

🕸 Large graphs

tens of thousands of nodes on a normal laptop

⬇ Export

SVG, PDF and PNG for reports and papers

Our rule in this coursePython computes · Gephi shows · your caption explains the settings.

Section 4

Three ways to get a graph into Gephi

Data Laboratory → Nodes → Add node; then Edges → Add edge. For tiny examples: Alice, Bob, Charlie with Alice → Bob and Bob → Charlie. Good for teaching — too slow for real data.

File → Import spreadsheet — import the nodes first, then the edges (“Append to existing workspace”). The column names matter:

nodes.csv   Id,Label,club
            0,0,Mr. Hi
edges.csv   Source,Target,Type,Weight
            0,1,Undirected,4

Our default. GEXF keeps weights and all attributes — and can carry time for the Timeline. nx.write_gexf(G, "karate_ch6.gexf"), then File → Open. Gephi also opens GraphML, GML, edge lists and Pajek files.

Step 6 · Homophily you can see

Keep the same layout and switch only Colour between Modularity Class and club. All four communities sit inside one club — except node 8 (Mr. Hi’s club, grouped with the officer’s community). Only 11 of 78 ties cross the clubs; assortativity +0.718 (Chapter 4). Switching one colour setting can test a hypothesis — but the club label came after the split; it is not a cause.

Section 9

Step 8 · Replay a cascade with the Timeline

Give every node a start time and mark the graph as dynamic — Gephi’s Window → Timeline → Enable then replays the spread (drag the window, press Play). Below: one Independent Cascade run from Chapter 5, and two real cascades from ev_cascades.csv (Lab 5.1).

import random
rng = random.Random(1)                          # one IC run, seed node 0, p = 0.25 (Chapter 5)
t = {0: 0}; frontier = [0]; step = 0
while frontier:
    step += 1; new = []
    for u in frontier:
        for v in G.neighbors(u):
            if v not in t and rng.random() < 0.25:
                t[v] = step; new.append(v)
    frontier = new
G.graph["mode"] = "dynamic"
for n in G:
    G.nodes[n]["adopted"] = "yes" if n in t else "no"
    if n in t: G.nodes[n]["start"] = float(t[n])
nx.write_gexf(G, "karate_cascade.gexf")
Timeline replay
One run is one story. The Timeline shows how a cascade spread — the simulations from Chapter 5 tell you how typical it is.

m = pd.read_csv("data/ev_mentions.csv"); users = pd.read_csv("data/ev_users.csv")
E = nx.from_pandas_edgelist(m, "source", "target", ["weight"], create_using=nx.DiGraph)
nx.set_node_attributes(E, users.set_index("user_id")["group"].to_dict(), "group")
m["score"] = m["sentiment"].map({"positive": 1, "neutral": 0, "negative": -1})
mean_sent = (m["score"] * m["weight"]).groupby(m["source"]).sum() / m.groupby("source")["weight"].sum()
for n in E:
    E.nodes[n]["mean_sentiment"] = round(float(mean_sent.get(n, 0.0)), 3)   # -1 ... +1
nx.write_gexf(E, "ev_mentions_ch6.gexf")       # pseudonymised IDs only
