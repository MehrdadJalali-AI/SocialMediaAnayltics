Section 3

What is a cascade — and how do we measure it?

A cascade is a structured record of how one piece of content spreads. Each event needs a cascade_id, post_id / user_id, a parent_id, a timestamp, a type (repost · reply · quote) — plus sentiment/stance (Ch 3) and community (Ch 4). No parent_id? Then paths must be inferred — and are uncertain.

Section 4

Broadcast or viral? Structural virality and phases

Structural virality (Goel et al., 2016) = the average distance between all pairs of users in the cascade. Load “Broadcast” and “Viral chain” in the cascade builder above: same size, very different spread (1.80 vs. 3.18).

Broadcast

One account posts, many repost it directly. Size 10, depth 1, breadth 9, virality 1.80. Typical for a news outlet.

Viral (person-to-person)

Content passes from user to user over many generations. Size 10, depth 6, breadth 2, virality 3.18. Typical for a meme.

Section 6 · Part B

Simulation model 1: Independent Cascade

Each newly active user gets one chance to activate each inactive neighbour, with probability p. A failed attempt is never repeated; the process stops when nobody new is activated. The result is random — so we run it many times.

Section 7

Simulation model 2: Linear Threshold

A user adopts when the share of active neighbours reaches their threshold θ — social reinforcement. 1 of 4 neighbours active → 25% < θ = 0.5 (no) · 2 of 4 → 50% ≥ 0.5 (adopt).

Seed selection: who should post first?

Compare four strategies (k = 3, Independent Cascade)

Sensitivity analysis

vary p or θ over a range · report mean and spread · check whether the ranking of strategies stays the same

Causality warning

A posted before B ≠ A caused B · both may react to the same news · simulations show what could happen, not what did

Responsible use

seeding can inform health messages… or manipulate opinion · no targeting of vulnerable groups

Report ranges, avoid causal language, and think about who could misuse the result.

InterpretWhat holds across all settings — and what does not?
import random, statistics as st
import networkx as nx
def independent_cascade(G, seeds, p, rng):
    active, frontier = set(seeds), list(seeds)
    while frontier:
        new = []
        for u in frontier:
            for v in G.neighbors(u):
                if v not in active and rng.random() < p:
                    active.add(v); new.append(v)
        frontier = new
    return len(active)
G = nx.karate_club_graph()
rng = random.Random(1)                 # fixed seed
def mean_reach(seeds, p, runs=5000):
    xs = [independent_cascade(G, seeds, p, rng) for _ in range(runs)]
    return st.mean(xs), st.pstdev(xs)
for p in [0.05, 0.10, 0.20, 0.30]:
    print(p, mean_reach([0], p))
# 0.1 -> mean 3.4, sd 2.3

Section 12

Theory summary

1 · Exposure ≠ adoption

we observe adoptions; exposure is mostly invisible.

2 · Cascade metrics

size, depth, breadth, speed — with clear definitions.

3 · Shape matters

broadcast vs. viral: structural virality.

4 · Two models

Independent Cascade (one contact) vs. Linear Threshold (reinforcement).

5 · Many runs, many settings

report ranges and sensitivity, not one run.

6 · No causal shortcuts

order is not cause; seeding can be misused.
